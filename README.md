# AutoLoc

## Présentation du projet

AutoLoc est une plateforme de gestion de location de véhicules multi-agences.

## Objectifs du projet

- Préparer l'environnement de développement du projet.
- Identifier les acteurs et les cas d'utilisation du système.
- Mettre en place les outils nécessaires au développement de l'application.

## Acteurs du système

- **Client**
- **Agent d'agence**
- **Responsable d'agence (Manager)**
- **Administrateur**

## Environnement technique

- Java 17+
- Maven
- IntelliJ IDEA Ultimate
- MySQL
- Postman
- Git et GitHub

## État d'avancement

Atelier 0 : mise en place de l'environnement de développement et initialisation du dépôt AutoLoc.
